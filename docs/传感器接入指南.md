# 传感器接入指南（智慧渔业养殖平台）

> 回答一个问题：**看板上某个塘口显示「待接入传感器」，怎么让它有数据？**
> 本文给出 4 种接入方式，从「零操作自动接入」到「真实硬件 RS232 接线」都有。

---

## 0. 先说结论：最快的两条路

| 你想做的事 | 怎么做 | 耗时 |
|---|---|---|
| **什么都不想配**，让新建的塘口自己有数据 | 保持「边缘网关模拟器」窗口开着即可，网关每 20 秒拉取一次塘口列表，自动为所有塘口上报数据 | 20 秒内自动完成 |
| **立刻就要看到数据** | 在「实时看板」该塘口卡片上点 **「一键接入传感器」** 链接 | 1 秒 |

> 前提：`启动服务.bat` 和 `启动模拟器.bat` 两个窗口都要开着。
> 如果模拟器没开，所有塘口都会停在「待接入传感器」。

---

## 方式一：自动接入（推荐，演示/答辩用）

`edge/gateway.py`（边缘网关）内置了**塘口自动发现**：

```
每 20 秒 → 请求 http://127.0.0.1:5000/api/v1/ponds
        → 拿到全部塘口 ID
        → 逐个生成/读取传感器读数
        → 通过 TCP 9000 上报给平台
```

所以你在「塘口管理」里新增一个塘口后，**不需要做任何额外操作**，最多 20 秒它就会出现在实时看板上。
网关控制台会打印：

```
[10:42:07] 塘口列表更新: TANK-A, TANK-B, TANK-C, TANK-D
[10:42:07] 上报 #4 共 4 个塘口
```

设备编号规则：`EDGE-GW-01-<塘口ID>`，例如 `EDGE-GW-01-TANK-D`。

---

## 方式二：页面「一键接入传感器」

实时看板上，没有数据的卡片底部会显示：

```
该塘口暂无水质数据 · 一键接入传感器（边缘网关也会在约 20 秒内自动接入）
```

点击后会调用 `POST /api/v1/sensor/simulate`，立即生成一条带时间戳的读数并触发阈值告警判定。

等价的命令行写法：

```bash
curl -X POST http://127.0.0.1:5000/api/v1/sensor/simulate ^
     -H "Content-Type: application/json" ^
     -d "{\"pond_id\":\"TANK-D\"}"
```

## 方式三：HTTP 上报（外接设备推荐，最简单）

任何能发 HTTP 请求的设备（ESP32 / 树莓派 / 4G DTU / 工控机）直接 POST 即可。

### 单条上报

```
POST http://<服务器IP>:5000/api/v1/water-quality
Content-Type: application/json

{
  "device_id": "DEV-001",
  "pond_id": "TANK-D",
  "timestamp": "2026-09-13 10:44:33",
  "metrics": {
    "temperature": 27.8,
    "ph": 7.7,
    "dissolved_oxygen": 6.3,
    "ammonia": 0.22
  }
}
```

响应：`{"code":0,"data":{"count":1},"message":"已入库 1 条"}`

### 断网补传（批量）

设备离线时把数据存在本地，联网后一次补传：

```json
{
  "type": "batch",
  "records": [
    {"device_id":"DEV-001","pond_id":"TANK-D","timestamp":"2026-09-13 09:00:00","metrics":{...}},
    {"device_id":"DEV-001","pond_id":"TANK-D","timestamp":"2026-09-13 09:05:00","metrics":{...}}
  ]
}
```

### 可直接运行的示例脚本

```bash
python scripts/push_demo.py TANK-D
```

## 方式四：RS232 串口 / TCP 长连接（真实传感器，符合 SRS 协议）

### 4.1 RS232 串口接入

1. 用 USB-RS232 转换器把水质传感器接到电脑，在「设备管理器 → 端口(COM 和 LPT)」里看端口号（如 `COM3`）。
2. 编辑 `config.json`：

```json
"collection": {
  "interval_seconds": 5,
  "serial": {
    "enabled": true,
    "port": "COM3",
    "baudrate": 9600,
    "bytesize": 8,
    "parity": "N",
    "stopbits": 1
  }
}
```

3. 重启 `启动模拟器.bat`。若串口打开失败会自动回退到模拟数据并在控制台提示。
4. 需要安装驱动库：`pip install pyserial`

### 4.2 RS232 帧格式（SRS 附录 A）

```
┌──────┬──────┬──────┬──────┬──────┬─────────────┬────────────┬──────┐
│ 0xAA │ 0x55 │ 地址 │ 功能 │ 长度 │  数据域 N   │ CRC16(2B)  │ 0x0D │
│      │      │ 1B   │ 1B   │ 1B   │  低位在前   │ Modbus/LE  │ 帧尾 │
└──────┴──────┴──────┴──────┴──────┴─────────────┴────────────┴──────┘
```

- 功能码 `0x01` = 上报水质数据
- 数据域 = 4 个 int16 大端，单位放大 10 倍：`水温(℃) / pH / 溶解氧(mg/L) / 氨氮(mg/L)`
- CRC16-Modbus：多项式 `0xA001`，初值 `0xFFFF`，校验范围「地址 → 数据域末字节」，低字节在前

**实例帧**（水温 27.5℃、pH 7.8、DO 5.2、氨氮 0.4）：

```
AA 55 01 01 08 01 13 00 4E 00 34 00 04 FF 13 0D
```

用 `server/protocol.py` 生成：

```python
from server.protocol import build_frame, build_water_payload
frame = build_frame(0x01, 0x01, build_water_payload(27.5, 7.8, 5.2, 0.4))
print(frame.hex().upper())
```

### 4.3 TCP 长连接上报

服务端在 **9000 端口**开 TCP Server（多线程，支持多设备并发）。

- 每帧 = 一个 JSON + 换行符 `\n`
- 心跳：`{"type":"heartbeat"}` → 服务端回 `pong`
- 数据：同上 `water-quality` 的 JSON 结构
- 也可以直接发**原始二进制 RS232 帧**，服务端会自动识别 `0xAA55` 帧头并校验 CRC

## 常见问题排查（卡片一直显示「待接入传感器」）

| 现象 | 原因 | 处理 |
|---|---|---|
| 全部塘口都是「待接入」 | 模拟器窗口没开 / 被关掉了 | 双击 `启动模拟器.bat` |
| 只有新加的塘口是「待接入」 | 网关已停止，或还没到 20 秒刷新点 | 等 20 秒；若超过 1 分钟仍没有，重启模拟器 |
| 数据停在某个时间不动 | 服务端被重启过，网关 TCP 断连 | 网关会自动重连；若没有，重启模拟器 |
| 串口接了真机但没数据 | 端口号错 / 波特率不匹配 / 没装 pyserial | 查设备管理器；`pip install pyserial`；看模拟器窗口的报错提示 |
| 平台上报后看不到 | 塘口 ID 与平台不一致 | 平台以「塘口管理」里的 `pond_id` 为准（如 `TANK-D`） |

## 数据字典（上报字段）

| 字段 | 类型 | 说明 | 合理范围 |
|---|---|---|---|
| `pond_id` | string | 塘口编号，必须与平台一致 | `TANK-A` 等 |
| `device_id` | string | 设备编号 | 任意，≤64 字符 |
| `temperature` | float | 水温 ℃ | 15 ~ 32 告警阈值外 |
| `ph` | float | pH 值 | 6.5 ~ 8.5 |
| `dissolved_oxygen` | float | 溶解氧 mg/L | ≥ 4.0 |
| `ammonia` | float | 氨氮 mg/L | ≤ 0.5 |
| `timestamp` | string | `YYYY-MM-DD HH:MM:SS`，可省略（默认当前时间） | — |

告警阈值可在 `config.json -> thresholds` 中修改。
